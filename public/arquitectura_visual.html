Detalle Técnico del Stack Tecnológico

☁️ Google Cloud Run & Jobs

Servicios serverless que escalan a cero. Cloud Run Jobs procesa el lote masivo en segundo plano por hasta 24 horas continuas con memoria dedicada, evitando timeouts HTTP de 60 segundos.

🪣 Google Cloud Storage

Recepción directa de archivos pesados (500K filas x 30 columnas) mediante Signed URLs. El archivo nunca pasa por la memoria RAM del servidor web, eliminando el error Heap Out-of-Memory.

🛡️ Capa Staging & Cuarentena

Aislamiento no destructivo en staging.import_errors. Las filas corruptas no abortan el lote, permitiendo procesar las válidas con estado COMPLETADO_CON_ERRORES.

🔐 Deduplicación Criptográfica

Change Data Capture (CDC) mediante hash SHA-256 / MD5. Si el archivo se procesa dos veces, las inserciones son exactamente 0, garantizando idempotencia estricta.

⚡ Eliminación Producto Cartesiano

La vista consolidated_tickets_view agrupa pagos e intereses en CTEs separadas antes del JOIN, evitando que M pagos x N intereses multipliquen el saldo adeudado.

🌐 Frontend React 18 + Vite

Desplegado en producción sobre CDN perimetral con routing SPA blindado. Incluye Mesa de Partes en vivo, módulo de 3 áreas y monitor de benchmark (>100K) con operador Gabriel Cabana.
